Closing-line value (CLV) tracker

Captures the first positive-EV quote per exact event, market, selection, line and sportsbook. After the event starts, it compares that entry price with the last pregame no-vig consensus price from at least two other complete same-line books. Positive CLV means the entry price beat the consensus close. This measures price quality, not betting profit, prediction accuracy or win rate.

Player props market board

Compares provider-supplied player prop quotes by player, market, over/under side, exact line and sportsbook. Player identity is kept separate from Over/Under so different athletes are never merged. This feed is opt-in and disabled by default because The Odds API requires individual event-odds requests for non-featured player markets. Each event request can consume quota; TheRundown Free currently supplies main markets only.
